# 🎬 Movie Reservation API

A robust and secure backend RESTful API for a Movie Reservation and Cinema Management System, built using **ASP.NET Core**, **Entity Framework Core**, and **Clean Architecture principles**. This system supports secure user management, role-based access control, movie showtimes, cinema management, and booking processing.

---

## 🚀 Features

- **User Authentication & Authorization**: Secure JWT (JSON Web Token) authentication with ASP.NET Core Identity.
- **Role-Based Access Control (RBAC)**: Separate permissions for `Admin` and `Customer` roles.
- **Clean Architecture**: Separation of concerns utilizing Repositories and Services pattern.
- **Database Management**: Entity Framework Core with SQL Server, featuring automated migrations and data seeding.
- **API Documentation**: Fully documented interactive API endpoints using **Swagger/OpenAPI**.

---

## 🛠️ Tech Stack

- **Framework**: .NET (ASP.NET Core Web API)
- **Database & ORM**: SQL Server, Entity Framework Core
- **Security**: Microsoft Identity, JWT Bearer Authentication
- **Documentation**: Swashbuckle (Swagger)
- **Containerization**: Docker & Docker Compose (Ready)
